# Phase 2 — Digital Advertising Budget Optimizer

This module focuses on analyzing digital advertising campaign performance and optimizing marketing budget allocation across Facebook, Instagram, Google, TikTok, and YouTube.

The project applies Big Data Analytics techniques to calculate key marketing performance indicators, compare data-processing approaches, and develop a data-driven Marketing Budget Recommendation Engine.

**Main Components:**
- Advertising campaign data generation and preprocessing
- CTR, CPC, CPA, conversion rate, and ROAS analysis
- Big Data simulation (10,000 to 10 million records)
- Pandas, MapReduce, and Apache Spark comparison
- Marketing Budget Recommendation Engine
- Interactive Streamlit dashboard

**Status:** In Development
